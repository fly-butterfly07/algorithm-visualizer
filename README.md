# 算法可视化站

一个单文件、零依赖的中文算法学习站点。整站内容装在一个 HTML 文件里，双击就能用：不安装、不构建、不联网、不加载任何外部字体或图片。

## 在线演示

GitHub Pages 开启后地址为 `https://fly-butterfly07.github.io/algorithm-visualizer/`（根目录的 `index.html` 会自动跳转到站点本体 `algorithm-visualizer.html`）。

本地打开：下载 `algorithm-visualizer.html`，双击即可。

## 两个浏览维度

同一个算法可以从两个角度进入，两处共用同一套步进与画布：

- **按用途**：上面 7 个分类，回答"这类问题该用什么"。
- **按思想**：暴力枚举、分治算法、动态规划、贪心算法、回溯算法、分支限界，共 6 种范式。每张范式卡片给出定义、适用场景、优缺点、复杂度与代表例子，并附一个可运行的示范算法。

归并排序同时属于"排序"与"分治"，站点只存一份，通过 `para` 标记在两个维度里复用。

## 交互

| 按键 | 作用 |
|---|---|
| ← | 上一步 |
| → | 下一步 |
| 空格 | 播放 / 暂停 |
| R | 重置 |
| + / - | 加快 / 放慢速度 |

进度条可以拖到任意一步。焦点在输入框或按钮内时不劫持按键，纯 Tab 也能走完全流程。参数（字符串、数组、目标值、规模等）改完即刻重新生成步骤并回到第 0 步。

## 画布

每一类算法都有自己的画布，不是通用表格：汉诺塔的三根柱、KMP 的模式串对齐、排序的柱状与桶、哈希的槽位、BST 的树形、图的结点与边、Floyd 的距离矩阵、Trie 的分叉、后缀数组的排序轮、SAM 的状态与 link、Manacher 的臂长、拓展欧几里得的系数表、筛法的数字网格、蒙特卡洛的散点、链表的指针圈。

配色带语义：橙 = 当前比较，青绿 = 已就位，蓝 = 移动中，红 = 失配，绿 = 匹配成功，灰 = 待处理或已排除，紫 = 指针。每个色块另配中文单字标签，去掉颜色也能分辨。

## 技术实现

- **单文件**：HTML、CSS、JavaScript 全部内联，无外部请求（源文件内 `https://` 出现次数为 0）。
- **快照契约**：每个算法产出一组快照 `{ draw, description, pseudoLine, variables, changedKeys, visited, finished, stats }`，`draw` 是纯数据而非 DOM 操作。
- **单一渲染入口**：`renderAll()` 读取 `APP.steps[APP.cursor]` 并重绘，前进、后退、拖动、播放共用同一条路径。
- **变量高亮**：`decorate()` 逐键比对相邻快照的变量值，生成 `changedKeys`，实现"这一行变了"的高亮，而不是写死。
- **连续动画**：位置变化用 FLIP 处理——先记录元素坐标，重排后再从旧位置过渡到新位置；位移时长随播放速度调整，并尊重 `prefers-reduced-motion`。
- **响应式**：窄屏下刻度、网格、矩阵单元按视口收缩，375px 宽度下无横向滚动。
