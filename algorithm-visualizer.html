怎么运行与切换

  • 双击本 .html 文件即可在浏览器打开，无需联网、无需安装、无需本地服务器。
  • 页面自带全部样式与脚本，不引用任何外部字体、图片或代码库。
  • 站点有两个浏览维度：按用途（递归与分治 / 字符串匹配 / 排序 / 查找 / 图论 / 数学·数论 / 其他经典）与按思想（暴力枚举 / 分治 / 动态规划 / 贪心 / 回溯 / 分支限界）。切换维度后点分类标签，再点算法卡片或「打开演示」。
  • 「按思想」维度下每个范式都有一张详情卡：核心思想、适用条件、优点、局限、复杂度特征与经典例子，并配一个可直接运行的演示。
  • 切换分类或算法会静默重新生成步骤并回到第 0 步，旧的自动播放会立刻停止。

怎么播放

  • 「下一步 / 上一步」逐帧查看；「播放」按速度自动推进，播放中变为「暂停」。
  • 速度分 0.5× / 1× / 2× / 4×（单步间隔 1200 / 600 / 300 / 150 毫秒），播放中切换即时生效。
  • 拖动或点击进度条可跳到任意步，播放中跳转会自动暂停。
  • 「重置」回到第 0 步，画布、说明、伪代码、状态四个面板一起同步回退。
  • 演示结束时播放按钮变成「重播」，点它从第 0 步重新播放。

可调参数与取值范围

  • 汉诺塔：圆盘数 n，2–6 的整数，默认 3。
  • KMP：主串长度 1–24，默认 ABABDABACDABABCABAB；模式串长度 1–12，默认 ABABCABAB。模式串长于主串时会走完流程并判定无匹配。
  • 冒泡 / 选择 / 插入 / 快速 / 归并 / 堆排序：规模 5–12，默认 8；可点「随机生成」换一组数，也可直接编辑数列（逗号或空格分隔）。
  • 计数排序：规模 5–9，元素需为 0–9 的整数（值域越大，计数数组越长）；桶排序：规模 5–9，元素需为 0–99 的整数；基数排序：规模 5–8，元素需为 100–999 的三位数（固定 3 趟）。
  • 二分查找：升序整数数组 5–12 个，默认 10 个；目标值为整数。
  • 顺序查找：候选整数 5–12 个（可无序）；插值 / 斐波那契查找：升序整数数组 5–12 个；目标值均为整数。
  • 哈希查找：关键字 4–8 个（1–99），桶数固定 7，冲突用链地址法；目标值可不在表中。
  • 树查找（二叉搜索树）：关键字 5–9 个且不重复，按输入顺序插入建树；目标值可不在树中。
  • 图论 10 个算法共用固定示例图，无需输入规模：有起点的算法（DFS / BFS / Dijkstra / Bellman-Ford / SPFA / Prim / Tarjan）可选起始结点，其余直接播放。示例图分别是 —— 遍历用 8 结点有向图、Dijkstra 用非负权图、Bellman-Ford / SPFA / Floyd 用含负权但无负环的图、Prim / Kruskal 用无向带权图、Tarjan 用 3 个强连通分量的图、匹配用左右各 4 点的二分图。拓扑排序与它们共用同一张 DAG，演示入口在「其他经典」类。
  • 字符串 7 个算法：KMP / BM / Sunday 输入「主串 1–24 字符 + 模式串 1–12 字符」，三者默认输入相同，可切着看比较次数的差别；Trie 输入 2–5 个单词（每个 1–6 个字母）与一个 1–6 字母的查询串；后缀数组输入 4–10 个字母、后缀自动机 4–8 个字母、Manacher 5–18 个字母，均只接受字母并自动转大写。
  • 暴力枚举 · 子集和：候选整数 3–6 个，默认 5 个；目标和为整数。
  • 动态规划 / 分支限界 · 0/1 背包：4 件固定物品（重/值 2/3、3/4、4/5、5/6），背包容量 4–10，默认 8。
  • 贪心 · 零钱兑换：面值 2–4 种（每种 1–10），默认 1、3、4；目标金额 3–12，默认 6（默认参数就是贪心非最优的反例）。
  • 回溯 · N 皇后：棋盘阶数 4–5，默认 4。
  • 其他经典 5 个：滑动窗口输入 4–14 个大写字母；双指针输入 5–10 个升序整数与目标和；快慢指针的链表固定为 4 个结点（值 3、2、0、−4），可选环入口 −1（无环）到 3；拓扑排序用固定 6 结点 DAG，直接播放；并查集元素个数 7–10，固定 6 次合并操作。
  • 数学 / 数论 10 个算法：欧几里得与扩展欧几里得输入 a（10–60）、b（4–40）；埃氏筛 N 为 20–100、欧拉筛 N 为 20–40；快速幂输入底数 2–9、指数 2–60、模数 7–97；矩阵快速幂求第 n 项（4–20）；组合数三角行数 n 为 3–8；卢卡斯定理输入 n（10–60）、k（0–n）与素数模数 2 / 3 / 5 / 7 / 11；蒙特卡洛撒点 40–200 个；随机化洗牌元素 5–12 个。
  • 修改参数即重新生成完整步骤并回到第 0 步，不需要确认。

六大算法范式速查

  • 暴力枚举：遍历全部可能，逐个验证。简单但指数级；例：子集和（本站演示）、百钱百鸡、暴力匹配、密码穷举。
  • 分治：拆成同构子问题，独立求解后合并。例：归并排序（本站演示）、快速排序、二分查找（本站演示）、汉诺塔（本站演示）、大整数乘法。
  • 动态规划：重叠子问题 + 最优子结构，存表避免重复计算。例：0/1 背包（本站演示）、LCS、爬楼梯、最短路、编辑距离。
  • 贪心：每步取局部最优，不一定全局最优。例：零钱兑换（本站演示，含反例）、哈夫曼编码、活动选择、最小生成树、Dijkstra。
  • 回溯：尝试 → 冲突则撤销 → 换分支，本质是带剪枝的 DFS。例：N 皇后（本站演示）、全排列、子集、数独、迷宫。
  • 分支限界：优先队列扩展节点，用界剪掉不可能更优的分支，求最优解。例：0/1 背包（本站演示）、旅行商 TSP、任务分配、整数规划。

查找算法速查（第二部分）

  • 顺序查找：逐个比较，不要求有序，O(n)；无序数据、链表、流式数据的唯一通用选择（本站演示）。
  • 二分查找：有序 + 随机访问，每次排除一半，O(log n)（本站演示）。
  • 插值查找：按目标在区间中的比例估算 mid，均匀分布时 O(log log n)，倾斜时退化 O(n)（本站演示）。
  • 斐波那契查找：用 F(k−1)−1 切分，mid 只用加减法，O(log n)，适合除法昂贵的场景（本站演示）。
  • 哈希查找：h(key) 直接定位桶，平均 O(1)、最坏 O(n)，只能做等值查找（本站演示，链地址法）。
  • 树查找：BST 平均 O(log n)、有序插入会退化；AVL 严格平衡、红黑树近似平衡（旋转少，Java TreeMap / C++ map / Linux 内核采用）、B+ 树多叉矮胖（MySQL InnoDB 索引）。本站演示二叉搜索树的查找路径。

数学 / 数论速查（第六部分）

  • 欧几里得：gcd(a,b) = gcd(b, a mod b)，余数为 0 即得答案，O(log min(a,b))（本站演示）。
  • 扩展欧几里得：同样的轮数里多带两个系数，得到 ax + by = gcd 的一组解，可求模逆元（本站演示）。
  • 埃氏筛：遇到未标记的 p 就认定素数，再从 p² 起划掉倍数，O(n log log n)（本站演示）。
  • 欧拉筛：每个合数只被最小质因子划一次，总划除次数等于合数个数，严格 O(n)（本站演示）。
  • 快速幂：指数二进制拆分 + 反复平方，O(log b)，每步取模防溢出（本站演示）。
  • 矩阵快速幂：把线性递推写成矩阵乘法，M^n 一次算出两项，O(k³ log n)（本站演示斐波那契）。
  • 组合数：帕斯卡三角逐格相加，O(n²) 预处理、O(1) 查表，全程只用加法（本站演示）。
  • 卢卡斯定理：p 为素数时把 n、k 写成 p 进制逐位相乘取模，O(log_p n)（本站演示）。
  • 蒙特卡洛：随机采样用频率估概率，误差按 1/√N 收敛，结果带随机性（本站演示估算 π）。
  • 随机化洗牌：Fisher–Yates 从后往前等概率抽，n! 种排列等可能，O(n) 且结果必然合法（本站演示）。

其他经典类型速查（第七部分）

  • 滑动窗口：左右指针同向移动，窗口内维持一个不变量（如「无重复字符」），右指针扩张、不满足就让左指针收缩，O(n)（本站演示最长无重复子串）。
  • 双指针（对撞）：有序数组两端各放一个指针，和偏小抬左端、偏大压右端，每步排除一整排候选，O(n)（本站演示两数之和）。
  • 快慢指针：慢指针 1 步、快指针 2 步，有环必相遇；相遇后一个指针回表头同速前进，再次相遇即环入口，O(n) 时间、O(1) 空间（本站演示链表判环）。
  • 拓扑排序（Kahn）：反复取出入度为 0 的点并删掉它的出边；输出个数少于结点数即有环，O(V+E)（本站演示 DAG）。
  • 并查集：parent 数组表示森林，查根判同集合；按大小合并 + 路径压缩后均摊 O(α(n))，适合连通性、Kruskal 与加边判环（本站演示 6 次合并）。
